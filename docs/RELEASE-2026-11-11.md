## Controles repetibles

Runtime: Node.js 24; revisión local iniciada con 24.20.0. Gestor: npm y `package-lock.json`. Instalar con `npm ci --no-audit --no-fund`; el audit se ejecuta expresamente después.

`node scripts/check-release.mjs` ejecuta, en este orden:

1. `npm run lint`.
2. `node --test` con todos los archivos `tests/*.test.mjs` enumerados por el preflight (contratos de release y regresiones del runtime).
3. `npm audit --audit-level=high`.

Después debe pasar `npm run build`: compila con Vite y revisa el grafo estático del artefacto con `scripts/check-bundle.mjs`. La entrada de Diseño no puede importar los motores opcionales 3D, Globe, streaming o Dev; tiene un límite de 600 kB de JavaScript sin comprimir. Pyodide debe cargarse únicamente al iniciar el juego. Este repositorio es JavaScript; no se añade un supuesto typecheck de TypeScript. El audit incluye dependencias de desarrollo y falla ante avisos altos/críticos o si no puede completar la consulta. No hay modo de omitir controles en el preflight.

Los tests contrastan referencias literales de medios/modelos/texturas, inventario de vídeos y pósters, alternativas de texto de la voz, relaciones caso/vídeo, datos de las rutas de detalle y claves/campos necesarios en ES/EN. Los metadatos opcionales `client` y `duration` de piezas editoriales pueden estar vacíos; no se rellenan con datos inventados. Las pruebas no dependen de red, credenciales ni del otro checkout. No sustituyen la revisión visual, la reproducción real, la comprobación de anchors o la disponibilidad de terceros.

El workflow `.github/workflows/ci.yml` ejecuta instalación congelada, preflight y build en PRs a `master` y pushes a `master`. Sus acciones están fijadas por SHA, con permisos de lectura, concurrencia limitada y máximo de 15 minutos. No hay tareas programadas, despliegues desde Actions ni un runner persistente en el equipo.

`vercel.json` ejecuta la misma instalación y `node scripts/check-release.mjs && npm run build`. El propio despliegue queda bloqueado si falla un control, también cuando GitHub Actions no puede arrancar. Se conserva el rewrite de las rutas SPA a `/index.html`. Un build normal lanzado directamente con `npm run build` no sustituye el preflight.
